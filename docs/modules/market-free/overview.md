# Módulo: Mercado Livre de Energia

**Estado: ⛔ Não implementado — planejado.**

Não existe funcionalidade de **Mercado Livre de Energia** (ACL) no sistema
atual. O produto hoje é focado em **geração distribuída** (homologação de
projetos FV junto à concessionária), que é o Mercado Cativo/regulado.

## Ideia (a definir)
Suportar migração/gestão de consumidores no ambiente de contratação livre:
análise de viabilidade, gestão de contratos, medição, etc. Domínio bem diferente
do atual.

## Próximos passos
- Levantar requisitos com o cliente; é um produto adjacente, não uma extensão
  trivial do fluxo de homologação.
- ADR quando houver decisão arquitetural.
