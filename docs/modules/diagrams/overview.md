# Módulo: Diagramas

**Estado: 🟡 Parcial / a definir.**

Este item da estrutura padrão **não corresponde a um módulo funcional** do
sistema atual. Há duas interpretações possíveis; documentadas para evitar
confusão:

1. **Diagramas de arquitetura/fluxo** (documentação): já cobertos por Mermaid
   nos `.md` deste repositório (ver `flow.md` de cada módulo e
   [architecture.md](../../project/architecture.md)).
2. **Diagrama unifilar elétrico do projeto** (feature de produto): **não
   implementado**. Seria a geração/anexação do diagrama unifilar exigido pelas
   concessionárias. Hoje o unifilar, quando existe, entra como **documento
   anexo** do projeto, não como recurso gerado.

## Situação atual
- Não há geração automática de diagrama unifilar.
- Diagramas de documentação usam Mermaid.

## Melhorias futuras
- Avaliar geração de unifilar a partir dos equipamentos e do padrão de entrada.
- Definir com o cliente qual dos dois sentidos é o desejado.
