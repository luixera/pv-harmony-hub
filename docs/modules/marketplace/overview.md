# Módulo: Marketplace

**Estado: ⛔ Não implementado — planejado.**

Não existe nenhum código de marketplace no sistema atual. Este arquivo é um
espaço reservado para quando o módulo for especificado.

## Ideia (a definir com o cliente)
Um marketplace poderia conectar integradores a fornecedores de equipamentos, ou
expor o catálogo central de equipamentos para cotação. Nada disso está definido
ou construído.

## Base existente que poderia ser reaproveitada
- **Catálogo de equipamentos** (`equipment_catalog`) — biblioteca central
  compartilhada de inversores/módulos com documentos.

## Próximos passos
- Definir escopo, atores e modelo de negócio antes de qualquer implementação.
- Criar um ADR quando a decisão arquitetural for tomada.

> **Não documentar regras de negócio aqui até o módulo existir** — para não criar
> documentação de algo que não foi construído.
